# Naive RAG from Scratch

A Retrieval-Augmented Generation (RAG) project built from scratch using:

- Python
- LangChain
- ChromaDB
- OpenAI Embeddings

## Project Goals

- Learn the architecture of a RAG pipeline
- Build a working question-answering system over custom documents - TBD
- Understand document loading, chunking, embeddings, retrieval, and generation

This project is being built incrementally with clear Git commits.
